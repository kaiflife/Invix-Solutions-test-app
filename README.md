# 🛒 Микросервис каталога товаров

Проект представляет собой отказоустойчивый микросервисный каталог товаров с интеграцией Telegram Mini App. Реализован в рамках тестового задания.

## 🛠 Технологический стек

*   **Фронтенд:** Next.js (App Router)
*   **Бэкенд:** FastAPI (Python 3.12)
*   **Telegram-бот:** aiogram 3.x
*   **База данных:** PostgreSQL 16
*   **S3 Хранилище:** MinIO
*   **Инфраструктура:** Docker, Docker Compose, Nginx (в роли API Gateway и балансировщика)
*   **Кэш / FSM:** Redis 7

---

## ✨ Функционал

1.  **Управление товарами (Telegram-бот):**
    *   При старте (`/start`) или обычном обращении бот предлагает открыть каталог.
    *   Для администраторов (ID задаются в `.env`) доступна кнопка «➕ Создать товар».
    *   Бот принимает фото и название (caption) одним сообщением, загружает изображение в MinIO, а данные сохраняет в PostgreSQL.
2.  **Просмотр каталога (Next.js):**
    *   Страница с заголовком «Каталог» и списком товаров.
    *   Работает как в обычном браузере, так и в качестве Telegram Mini App.
3.  **Отказоустойчивость (Stateless):**
    *   Все компоненты спроектированы без хранения состояния в памяти.
    *   FSM-состояния бота хранятся в Redis, что позволяет запускать несколько инстансов бота одновременно.
    *   Файлы не сохраняются на дисках контейнеров, а стримятся напрямую в S3.
    *   Запросы балансируются через Nginx.
